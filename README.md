## Pages
- `index.html` — Home
- `projects.html` — Projects
- `ai.html` — AI-generated page (requirement)

## Creative Addition
- Theme toggle (light/dark) implemented with vanilla JavaScript (ES6 module).

## Folder Structure
- `css/` — styles
- `js/` — JavaScript modules
- `images/` — images and favicon
